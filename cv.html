Gerrit-Jan de Bruin

Utrecht · gerritjan.debruin@gmail.com · gerritjandebruin.nl

I am a research software engineer at TNO, in the group Environmental Modelling, Sensing & Analysis. I make measurement data usable: from sensor networks, our measurement van and the Cabauw site to datasets that researchers, inspectors and policy makers can work with.

I trained as an analytical chemist at the University of Amsterdam and obtained my PhD at Leiden University on network analysis for smart inspection, together with the Human Environment and Transport Inspectorate. What I value most is work that gets used, with data, code and choices that others can trace.

Software

  • DAQ: data acquisition chain of TNO's measurement van and the Cabauw site, written in Python, with initial ideas from the ACTRIS software: from Azure IoT Hub to Parquet, a Python query package, a FROST SensorThings server and campaign dashboards. Internal TNO software.
  • Dustmonitoring: TNO's platform for particulate matter sensor networks, including the public ILM2 dashboard. Internal TNO software, which I maintain and modernise.
  • Ship emissions: processing of the sniffer station measurements near the port of Rotterdam, with automatic calculation of the fuel sulphur content (FSC) of passing ships, presented in a web frontend. Internal TNO software.
  • SARA: sample registration software for our lab, my first fully vibe-engineered application. Built in 40 hours (October-November 2025), it replaced software costing €10,000 a year. Azure, SQL, JavaScript and a Python API backend. Internal TNO software.
  • gaussian-plume: Python implementation of the Gaussian plume model, developed in the EU LIFE project CLINSH.
  • Code for my papers: cargo-ship-noncompliance-assessment, temporal-link-prediction and truck-codriving.
  • Chemical attribution of fentanyl: Python code, with J.M. de Bruin-Hoegée, used in Chemical attribution of fentanyl: The effect of human metabolism, Forensic Chemistry, 100330, 2021.
