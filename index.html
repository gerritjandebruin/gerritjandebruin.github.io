Software

-

DAQ: the data acquisition chain of TNO's measurement van and the Cabauw site. Instruments send their data through Azure IoT Hub; it is stored as Parquet, read by researchers with a Python package, and passed on to a FROST SensorThings server and daily campaign dashboards. Names follow the W3C/OGC SOSA/SSN standard for sensor data. Internal TNO software.

-

Dustmonitoring: TNO's platform for particulate matter sensor networks, from the sensor boxes to the database, API and web applications, such as the public dashboard of the ILM2 network. Internal TNO software, which I maintain and modernise.

-

Ship emissions: processing of the measurements at the sniffer station near the port of Rotterdam for the Human Environment and Transport Inspectorate (ILT), from raw instrument data via Parquet to exhaust plumes linked to individual ships with AIS. Internal TNO software.

-

gaussian-plume: Python implementation of the Gaussian plume model for the dispersion of air pollutants, developed in the EU LIFE project CLINSH.

-

cargo-ship-noncompliance-assessment: code for Fair automated assessment of noncompliance in cargo ship networks (2022).

-

temporal-link-prediction: code for Supervised temporal link prediction in large-scale real-world networks (2021).

-

truck-codriving: code for Understanding Behavioral Patterns in Truck Co-driving Networks (2018).

-

Chemical attribution of fentanyl: Python code, with J.M. de Bruin-Hoegée, used in Chemical attribution of fentanyl: The effect of human metabolism, Forensic Chemistry, 100330, 2021.

-

biomarker-profiling-plants: chemometric analysis of LC-HRMS/MS data to tell exposure of plants to chlorine gas apart from exposure to bleach.
